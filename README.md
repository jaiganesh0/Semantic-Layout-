# Day 1 - Task 1: Semantic Layouts & Styling

Responsive landing page for **SUGHI LED TVL** (LED screens, live streaming, event setup).

## What is used
- Semantic HTML: `header`, `nav`, `main`, `section`, `article`, `ol`, `footer`, skip link
- **Flexbox**: header/nav, hero, button row, event tags
- **CSS Grid**: LED pixel panel, services grid (`auto-fit` + `minmax`), process steps
- Typography: Bricolage Grotesque (headings) + Source Sans 3 (body), a 1.25 type scale with `clamp()`, line length under 65 characters
- Responsive from phone to desktop, visible focus states, reduced-motion support

## Run
Open `index.html` in a browser. No build step.
